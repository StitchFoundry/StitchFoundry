# StitchFoundry v0.15.0 (draft release notes)

Suggested version: **v0.15.0** (changes since v0.15.0-rc.1). Draft for the owner to approve; no version bump, tag or release is made by this PR.

## New
- **Hoop editor.** Pick your machine and hoop, see the hoop on the canvas, Fit to Hoop, quick rotate / flip / resize, and a hoop orientation test.
- **My Machine.** Choose the save format per machine and make it the default for Save and Export.
- **Start a design in the hoop.** Pick machine, hoop and fabric first; new designs remember the last hoop you used. The Home screen hoop tiles now open a ready design.
- **Make a Design: lettering.** Multi-line text with font, alignment and per-line size.
- **Clipart.** Searchable clipart sets and 20 new original motifs.
- **Monogram frames.** 11 new decorative monogram frame templates (20 in the gallery).
- **Learn button.** Opens a lesson list loaded from stitchfoundry.app.
- **Report a Bug / Suggest a Feature** open the web forms.
- **Font editor.** Open a font by name or folder as a font document and remove glyphs.
- **Jump and trim counts per colour** in the embroidery panel.
- **Send to my phone** (cloud side): private 24-hour file links.
- **Founding members:** numbered badges and a one-time bonus.
- **Sign-up limits:** a daily sign-up cap with next-day queue and a per-user daily free AI limit.
- Plain-language advice when a design is too stiff, now translated into all supported languages.

## Changed
- The Foundry Account is now the only AI sign-in (the "use my own API key" option is gone).

## Fixed
- Scaling lettering now scales each line's own size.
- A very small satin split length is raised to a safe minimum.
- Plain fills are capped so huge fills can't make runaway stitch counts.
- A damaged XXX file can no longer overflow on 32-bit builds.
- Bug-report queue numbering can't overflow.
- Dates are read through the standard time library.
- Replaced a yanked dependency; old links and workflow references updated after the organisation move.
