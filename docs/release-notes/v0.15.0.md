# StitchFoundry v0.15.0 (draft release notes)

Draft for the owner to approve. No version bump, tag or release is made by this change. It lists only what is merged on `main` since v0.14.0 (checked against the merged pull requests).

> **Maturity:** StitchFoundry is pre-release embroidery software. Test-sew every design on scrap fabric first.

## New
- **Hoop editor.** Pick your machine and hoop, see the hoop on the canvas, Fit to Hoop, a warning when a design goes over the field, custom hoops, and an owned-hoop picker that remembers the last hoop per machine.
- **Quick transform.** Rotate (including 90-degree rotate with shortcuts), flip and resize, with buttons in the Embroidery panel.
- **Hoop orientation test** and a per-machine export rotation.
- **My Machine.** Choose the save format per machine and make it the default for Save and Export. Machine profile editor with profile sync.
- **Start a design in the hoop.** Pick machine, hoop and fabric first; new designs remember the last hoop you used. The Home screen hoop tiles open a ready design.
- **Make a Design: lettering.** Multi-line text with font picker, justification, line spacing and per-line size.
- **Clipart.** Searchable clipart sets and 20 new original motifs.
- **Monogram frames.** 11 new decorative monogram frame templates (20 in the gallery).
- **Auto-Digitize presets** for cartoons and logos.
- **Underlay presets.** Named underlay presets, with a picker on fill and satin properties.
- **Learn button** with a lesson list loaded from stitchfoundry.app, plus a plain-words glossary and written lessons.
- **Report a Bug / Suggest a Feature** open the web forms.
- **Font editor.** Open a font by name or folder as a font document, see it and remove glyphs.
- **Jump and trim counts per colour** in the embroidery panel.
- **Applique check:** open a design in the check test.
- **Quilting tile generator** and a `quilt.tile` command that writes DST (first slice).
- **Web app:** favicon, description and link-preview tags; a staging switch (`?services=staging`).
- **Cloud side (Foundry Account):**
  - Send to my phone: private 24-hour file links.
  - Founding members: numbered badges and a one-time bonus.
  - Daily sign-up cap with next-day queue, a sign-up guard (disposable emails, per-IP limit) and a per-user daily free AI limit.
  - A free starter pack of 12 designs (DST, PES and preview).
  - A "Get updates" sign-up request.
- Plain-language advice when a design is too stiff, translated into all supported languages.

## Changed
- The Foundry Account is now the only AI sign-in (the "use my own API key" option is gone).
- Bug-report scrubbing keeps dates, sizes and stitch counts and hides names more reliably.
- A new Foundry Account confirms its email before it spends.
- The QA report lists unverified hoop sizes and golden/overlay results.

## Fixed
- Scaling lettering now scales each line's own size.
- A very small satin split length is raised to a safe minimum.
- Plain fills, run, zigzag and satin stitches and decoration stitches are capped per object so a huge object can't make a runaway stitch count.
- Embroidery file names can no longer become Windows device names.
- A damaged XXX file can no longer overflow on 32-bit builds.
- The multi-hoop hooping count can't wrap past its cap; renaming a custom hoop never replaces another one; machine profile names and counts are limited.
- Bug-report queue numbering can't overflow.
- The web app ignores the malformed key and input events that browser autofill sends.
- Exports are checked stitch by stitch at each orientation offset (DST, PES, JEF, EXP).
- Dates are read through the standard time library.
- Replaced yanked dependencies; old links and workflow references updated after the organisation move.

## Not in this release
The hoop-first workspace (overlay toggle, zoom presets and embroidery-first toolbars) is coming in the next release.
